# 智慧校园证件照标准化预处理系统

## 项目简介

本项目是一个基于Python + OpenCV + PyQt5开发的智慧校园证件照标准化预处理GUI系统，主要用于校园一卡通、学生证等证件照的自动预处理。

## 附：智慧快递包裹条码增强与识别预处理系统（题目 14）

本目录同时提供题目 14 的条码预处理 GUI，包含去噪、可调锐化、阈值二值化、形态学开运算与多图对比/批量保存。

- 启动：`python BarcodeGUI.py`
- 测试数据目录：`barcode_test_dataset/`
- 清晰度对比表：`条码清晰度对比表.md`

## 功能特性

### 核心功能
1. **图像导入**
   - 支持从文件选择导入证件照
   - 支持摄像头实时拍摄
   - 支持批量导入处理

2. **尺寸标准化**
   - 支持多种标准证件照尺寸（一寸、二寸、小一寸等）
   - 自动人脸检测与定位
   - 智能居中裁剪
   - 保持人脸比例

3. **背景替换**
   - 支持蓝/白/红三种标准背景色
   - 多种分割算法（GrabCut、颜色范围、边缘检测）
   - 边缘羽化处理
   - 背景平滑优化

4. **图像增强**
   - 亮度/对比度调节
   - 直方图均衡化
   - 多种去噪算法（中值滤波、高斯滤波、双边滤波）
   - 自动白平衡
   - 锐化处理

5. **一键标准化**
   - 预设多种处理方案（学生证、一卡通、考试报名等）
   - 自动完成所有预处理步骤
   - 批量处理支持

6. **结果保存**
   - 原图/效果图对比显示
   - 支持多种格式保存（JPG、PNG、BMP）
   - 批量导出功能

## 安装与运行

### 环境要求
- Python 3.8+
- OpenCV 4.5+
- PyQt5 5.15+
- NumPy

### 安装依赖
```bash
pip install opencv-python opencv-python-headless pyqt5 numpy
```

### 运行程序
```bash
python IDPhotoGUI.py
```

## 使用说明

### 1. 启动程序
运行 `IDPhotoGUI.py`，系统将显示主界面。

### 2. 导入图像
- 点击左侧导航栏"导入图片"按钮
- 或在中央图像区域点击"打开图片"
- 支持格式：JPG、PNG、BMP、TIF

### 3. 选择处理方案
在右侧控制面板选择预设方案：
- **学生证标准**: 一寸蓝底，自动增强
- **一卡通标准**: 一寸白底，自动增强
- **考试报名**: 二寸蓝底，轻度处理
- **护照签证**: 二寸白底，自动增强

### 4. 一键处理
点击"一键处理"按钮，系统将自动完成：
1. 人脸检测与定位
2. 尺寸标准化裁剪
3. 背景替换
4. 图像增强

### 5. 手动调整（可选）
如需手动调整，可使用：
- **尺寸标准化面板**: 调整目标尺寸、人脸检测选项
- **背景替换面板**: 选择背景颜色、分割算法
- **图像增强面板**: 调节亮度、对比度、去噪等

### 6. 保存结果
点击"保存导出"按钮，选择保存路径和格式。

## 技术特点

### 人脸检测
- 采用OpenCV DNN人脸检测器
- 支持Haar级联分类器备用方案
- 自动计算最佳裁剪区域

### 背景替换
- GrabCut算法：高精度分割
- 颜色范围分割：快速处理
- 边缘检测：适用于复杂背景
- 边缘羽化：自然过渡效果

### 图像增强
- 自适应直方图均衡化（CLAHE）
- 双边滤波：保留边缘的去噪
- 非局部均值去噪：高质量去噪
- 自动白平衡

## 注意事项

1. **图像质量**: 建议使用分辨率不低于600×800的图像
2. **人脸要求**: 正面照效果最佳，侧脸可能不符合证件照标准
3. **背景要求**: 纯色背景处理效果最佳
4. **合规性**: 系统仅提供技术处理，最终合规性需人工确认
